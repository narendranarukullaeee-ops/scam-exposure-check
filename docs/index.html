        How the real app works

        1. You confirm your own email with a one-time code, so nobody can look up someone else. The demo skips this step.
        2. The app checks that one address against a breach database. The demo uses simulated records instead.
        3. A fixed rule engine scores the exposure, ranks the scam scripts it makes believable, and lists every point.
        4. If an API key is set, an AI model rewrites the result in plain English. It never sees the email or changes the score.
        5. Nothing is stored: not the email, the code or the result.
